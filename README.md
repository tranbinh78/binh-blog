# Chirpy-like Jekyll site for Binh-blog (prepared)

This package is a Chirpy-style Jekyll site skeleton prepared to run on GitHub Actions.

Instructions:
1. Download and unzip this package.
2. Copy your existing `grammar/` folder into the root of the unzipped repo (do NOT overwrite _config.yml unless you want to).
3. Commit and push to `main` branch.
4. The GitHub Actions workflow will build and deploy the site automatically to GitHub Pages.

Notes:
- If your repo is `tranbinh78/binh-blog`, the site will be served under `https://tranbinh78.github.io/binh-blog/` per `_config.yml`.
- Ensure `avatar-binh.png.jpg` is placed into `assets/img/` if you want the avatar.
